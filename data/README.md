# Описание данных

Исходный датасет содержит объявления о продаже недвижимости в Санкт-Петербурге и населённых пунктах Ленинградской области.

## Таблицы

### `advertisement`

Информация об объявлениях:

- `id` — идентификатор объявления;
- `first_day_exposition` — дата публикации;
- `days_exposition` — продолжительность размещения в днях;
- `last_price` — указанная стоимость объекта.

### `flats`

Характеристики объектов недвижимости:

- `id` — идентификатор квартиры;
- `city_id` — идентификатор населённого пункта;
- `type_id` — идентификатор типа населённого пункта;
- `total_area` — общая площадь;
- `rooms` — количество комнат;
- `ceiling_height` — высота потолков;
- `floors_total` — количество этажей в доме;
- `living_area` — жилая площадь;
- `floor` — этаж квартиры;
- `is_apartment` — признак апартаментов;
- `open_plan` — признак открытой планировки;
- `kitchen_area` — площадь кухни;
- `balcony` — количество балконов;
- `airports_nearest` — расстояние до ближайшего аэропорта;
- `parks_around3000` — количество парков в радиусе трёх километров;
- `ponds_around3000` — количество водоёмов в радиусе трёх километров.

### `city`

Справочник населённых пунктов:

- `city_id` — идентификатор;
- `city` — название населённого пункта.

### `type`

Справочник типов населённых пунктов:

- `type_id` — идентификатор;
- `type` — тип населённого пункта.

## Связи

- `advertisement.id` → `flats.id`;
- `flats.city_id` → `city.city_id`;
- `flats.type_id` → `type.type_id`.

## Доступность данных

Исходные данные не размещены в репозитории, поскольку использовались в учебной базе данных. Репозиторий содержит SQL-запросы, описание методики, результаты анализа и визуализации.
